# Deep Learning Notes

个人深度学习自学记录，包含概念笔记、PyTorch 实验和错误分析。

## 内容

| 模块 | 内容 |
|---|---|
| 训练基础 | MLP、损失、优化、训练与评估 |
| CNN | 卷积、池化、通道、感受野 |
| NLP | 文本处理、词向量与序列模型，持续更新 |

## 运行环境

Windows，Conda，Python，PyTorch，Jupyter Notebook。
小规模实验使用 CPU。
具体版本与运行步骤随各实验补充。

## 使用方式

笔记位于 notes，实验位于 notebooks，图片位于 assets。
Notebook 中的训练单元格需要手动运行，避免重复训练。
